# NetClaw 1.13.1

Minor fixes for four open issues, implemented using Spec Kit in chronological
order: #262, #300, #301 and #302. This is a coordinated patch release for
Specs 156–159; source version advances from 1.13.0 to 1.13.1.

## Changes

- **#262 — MCP defaults:** Replace shell-style fallback expressions in the source
  OpenClaw template with a separate non-secret defaults catalog. Installer and
  setup translators materialize absent/empty optional defaults, including URL
  fields, while preserving explicit overrides and required-input checks.
- **#300 — Canvas retry:** Store immutable inherited context with the private
  conversation binding so failed Hermes setup and restart retain its ancestry.
- **#301 — Chat recovery:** Retain the original submitted prompt and transcript
  anchor. Status recovery preserves edited/cleared drafts, merges the confirmed
  original turn once, and refuses ambiguous history attribution.
- **#302 — Admission recovery:** Add separately confirmed “Release slot and start
  new chat” for owned unknown admissions without native run IDs. Durable audit,
  unknown outcome, evidence and nonce remain; old work never replays. Owned
  history restores request identity after tab storage loss.

## Upgrade and compatibility

Update source and rebuild the HUD; upgrade the private Hermes bridge with it.
No owner runtime, provider configuration or device is changed by this release.
Existing ledgers add the release-audit table on open. Ordinary acknowledgment,
restart and stop do not release capacity. The explicit action accepts possible
continued execution alongside new work; native concurrency checks remain.

Regenerate MCP registrations through the installer/setup workflow instead of
copying the source template directly. Re-run registration after adding an
optional override that was previously materialized. Existing managed defaults
migrate with backups; custom values remain preserved. Nautobot lab mode now
matches the shared explicit-opt-in default of false.

The fallback incompatibility is verified against qualified OpenClaw 2026.7.1-2;
newer upstream releases may support fallback expressions. Legacy Canvas bindings
without stored ancestry cannot reconstruct it safely. Legacy Chat receipts without
original submission metadata require owned-history review rather than guessed
prompt attribution. Extension 1.3.1 source records the added setup-review inputs;
Marketplace distribution is a separate operation.

## Validation and known limitations

- 117 focused configuration/installer Python checks passed. All 124 registered
  entries resolved through the actual qualified native substitution module with
  synthetic required values; no gateway/provider execution.
- Full HUD suite: 383 passed, zero failures/skips. HUD production build passed.
- Hermes Python: 24 passed, six explicit real-Hermes fixture skips locally.
  Actual SQLite, controlled HTTP and real React/JSDOM cover lost admissions,
  restart, no-replay, owner checks, draft recovery and confirmation/cancellation.
- Existing bundle-size advisory and previously documented platform/provider
  qualification limits remain. This patch does not claim new live acceptance.
