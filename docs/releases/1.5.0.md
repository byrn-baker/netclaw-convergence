# NetClaw 1.5.0

FastMCP 4 and MCP SDK 2 support for the migrated scope of coordinated specs 141 and 142. This is a source release; the full external fleet migration remains open.

## Changes

- Upgrade all 35 repository-owned FastMCP servers to FastMCP 4.0.11 and MCP Python SDK 2.3.0, the latest stable versions verified on 2026-10-04.
- Support modern `2026-07-28` and legacy protocol negotiation. Dot and the reviewed UML HTTP launcher use explicit stateless HTTP while retaining application authentication and safety controls.
- Install compatible external servers with reviewed, hash-checked source patches and isolated component bounds. Refuse unknown source edits instead of silently patching them.
- Build and verify GAIT runtime generations with matching bundled source before promotion, with a tested restore path.
- Add framework, installer, protocol and security regression checks, reproducible catalog evidence and a fleet disposition inventory.

## Upgrade and compatibility

Retain the previous checkout, external sources, launch configuration and isolated runtime directories before upgrading. Install and validate in a separate checkout, then switch launch configuration. Restore matching source and interpreter together on rollback. General component pip installation is not transactional. No live installations or network devices are changed by publishing this release.

Existing stdio defaults remain. Legacy low-level SDK integrations keep separate bounds. Strict unknown-argument validation and framework schema metadata change; Claroty's existing `Any` arguments now advertise unrestricted JSON correctly. Stateless transport does not remove application persistence or make local stores safe across replicas. Automatic retries, caching and code execution are not globally enabled. Optional Tasks are selectively enabled as described below.

## Validation and known limitations

All 35 owned servers passed real client catalog discovery in both protocol modes, exposing 450 tools; all 35 dependency manifests resolved for Python 3.12. External discovery passed 33 probes with 767 tools (including a retired seven-tool Catalyst reference). Baselines were available for 29 owned servers; no before/after parity is claimed for the other six. Component tests, security/installer regressions, GAIT staging/rebuild/restore and repository reconciliation passed as recorded in the verification report. Catalog probes block outbound sockets and do not execute vendor operations.

Five external integrations remain on their existing runtimes pending native ports or deliberate replacement: Atlassian, AWS Cost Explorer, AWS Diagram, PagerDuty and Blender. RADKit has reviewed migration patches but could not be validated without its licensed client dependency. Live vendor credentials, full HTTP authorization matrices and every supported Python/OS combination have not been tested. These exceptions are not counted as successful upgrades.

## Asynchronous MCP Tasks

Enable 298 tools across 35 integrations: 242 in 30 owned servers, 34 in NetBox/SD-WAN/NVD/Wikipedia, and 22 in the pinned pyATS upstream implementation. Task-aware clients receive handles and poll while work continues; non-declaring clients retain foreground results. pyATS retains completed results in SQLite and avoids replaying unknown outcomes. Other enabled servers use FastMCP Tasks 4.0.11 with ephemeral memory by default, isolated queue names and one embedded worker per server. Redis durability and multi-replica operation require separate acceptance.

Seven focused NetClaw task tests and the pinned upstream pyATS suite (137 passing tests) verify real SDK/HTTP behavior with simulated I/O. No live-network speedup or deployment is claimed.
