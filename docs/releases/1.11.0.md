# NetClaw 1.11.0

Spec: [152 — Workspace files and claw controls](https://github.com/automateyournetwork/netclaw/blob/v1.11.0/specs/152-workspace-claw-controls/spec.md).

## Changes

The VS Code extension's upper Connections panel opens SOUL.md, AGENTS.md,
IDENTITY.md, USER.md, TOOLS.md and HEARTBEAT.md from the selected OpenClaw or Hermes
installation. Native Markdown editing supports reviewed save and upload/overwrite,
private original backups and stale-revision refusal. There is no delete or rename.

Installation-bound Start, Stop and Restart cover the verified owned gateway/engine,
HUD/companion and configured federation services. Offline Start survives editor
reload. Save & Restart runs only after the reviewed content is verified on disk.
WSL-discovered fixes preserve native OpenClaw home/tilde resolution and isolate
systemd service discovery from neighboring installations.

## Upgrade and compatibility

Source release 1.11.0 and Marketplace extension 1.1.0 have independent versions.
The new panel requires this release's source HUD/helper and the running HUD's
session-authenticated management discovery route. Upgrading only the extension does
not add that route to an older HUD. Use the existing installation's upgrade/change
workflow, then reconnect and review the exact local management binding. The extension
does not install, adopt or reconfigure services automatically.

Full lifecycle requires durable verified service ownership. The managed HUD launcher
is documented in the [extension guide](https://github.com/automateyournetwork/netclaw/blob/v1.11.0/extensions/netclaw-vscode/README.md).
Native Windows runtime management is unsupported; use the actual WSL extension host.
No provider credentials, installed personas or service definitions are shipped.

## Validation and known limitations

See [release verification](https://github.com/automateyournetwork/netclaw/blob/v1.11.0/specs/152-workspace-claw-controls/release-verification.md),
[Mac verification](https://github.com/automateyournetwork/netclaw/blob/v1.11.0/specs/152-workspace-claw-controls/verification.md)
and [WSL observations](https://github.com/automateyournetwork/netclaw/blob/v1.11.0/specs/152-workspace-claw-controls/wsl-verification.md).

Mac native source and installed artifact checks cover both runtime fixtures, every
file, exact upload bytes, Save & Restart, process lifecycle and offline editor recovery.
WSL verified real regular-file reads, continuous typing and Undo. Four real symlink
entries were refused by design; symlink editing is not supported. WSL did not exercise
real file overwrites or live full lifecycle. Ownership ambiguity keeps controls
unavailable. Fixture performance does not establish production CLI latency, and
service readiness does not prove prompt consumption. Hermes's protected HUD engine
continues to exclude persona context.
