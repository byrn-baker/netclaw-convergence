# Announcement draft — NetClaw 1.0.0

NetClaw 1.0.0 is here: the first official versioned release of the AI network engineering coworker.

This milestone brings together 233 skills and 173 MCP integrations with a new operations HUD: Basic/Advanced views, Claw and MCP drill-downs, cited RAG retrieval, Tokenomics, Logs, Configuration, Security and Documentation. Adam Mason's Canvas investigation workspace remains at the heart of the experience.

Run one NetClaw or coordinate a risk of specialist NetClaws through a Border. Add the optional Jev Science Officer for advisory assessments. Work through chat, the HUD, mobile clients or configured Zoom integration—with the same observation, approval, verification and audit discipline for network changes.

We're also making contribution expectations explicit: every PR starts from a numbered spec and follows Spec Kit through planning, tasks and verification. Future feature specs advance the 1.x minor version; fixes and maintenance advance the patch.
