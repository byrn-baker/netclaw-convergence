# NetClaw 1.15.0

Spec: [1010-convergence-development](https://github.com/byrn-baker/netclaw-convergence/blob/v1.15.0/specs/1010-convergence-development/spec.md).
This is source-version metadata for the Convergence fork, not an upstream NetClaw release announcement.

## Changes

Adds a project-local Convergence coding skill with researcher, scoped implementer
and independent verifier contracts. The bounded Ralph-style workflow records
acceptance and progress in the active numbered spec, shares a three-attempt-per-task
and 45-minute run budget, preserves counts on resume, and separates review-only
requests from implementation. See the [development guide](https://github.com/byrn-baker/netclaw-convergence/blob/v1.15.0/docs/convergence/development.md).

## Upgrade and compatibility

No service migration, dependency update, global assistant setting or runtime agent
configuration is required. Use the coding skill from a checkout containing it.
Hosts without delegation tools use sequential work and report that limitation.
Installation remains handled by the existing Convergence setup skill. This does
not install a background Ralph process, enforce OS timeouts or cap monetary spend.

## Validation and known limitations

Skill packaging, local links, whitespace and the new spec artifacts passed.
Independent review resolved review-only routing; disposable scenario evaluations
verified successful completion, blocked platform coverage, expired budgets and
verification-only retry accounting. These synthetic fixtures do not qualify macOS
or installed runtime behavior. See the [verification record](https://github.com/byrn-baker/netclaw-convergence/blob/v1.15.0/specs/1010-convergence-development/verification.md).

The fork retains pre-existing spec-artifact, FastMCP dependency, startup-fixture
and unit-runner dependency failures. This version metadata does not declare the
entire repository CI green. The upstream Convergence scope proposal remains open.
No Git tag or published release is implied by committing these source files.
