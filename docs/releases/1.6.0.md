# NetClaw 1.6.0

## Changes

Add local John and Lobster avatars as the fourth HUD Chat interface. The avatar
shares the existing conversation, configured model, history and approvals.
Camera controls, keyboard navigation, reduced motion and graphics recovery keep
Chat usable alongside the animated character. Authenticated macOS system speech
defaults to a fixed status notice; full answers are spoken only on request or
explicit opt-in. Playback supports bounded clips, speed/volume and cancellation.

Repair HUD model/history RPC compatibility with the installed OpenClaw runtime
and preserve the intended CLI while selecting its Node interpreter. Include an
optional, disabled experimental Tavus foundation with separate constrained agent,
local evidence and conservative usage reservations.

## Upgrade and compatibility

Update the repository and refresh HUD dependencies with npm ci, then rebuild.
No device configuration or runtime gateway restart occurs from the source change.
Existing Chat and Canvas remain. Local rendering needs WebGL; local speech
currently requires macOS system voice. Other hosts report unavailable speech
without a hosted fallback. No Blender installation is required to use the assets.

Select Chat to stop using Avatar. To roll back code, restore the previous source
and matching npm dependencies. Retain private gateway backups and provider usage
ledgers; end/reconcile any experimental hosted call before disabling its runtime.

## Validation and known limitations

Closeout checks: 358 HUD tests passed; one existing macOS fixture could not bind
127.0.0.2 (EADDRNOTAVAIL). Four Python boundary/setup tests, production build and
repository declaration reconciliation passed. Applicable Linux CI must pass
before merge. The owner confirmed initial live avatar/audio; final polish has
component test coverage but no new automated viewport/speaker acceptance.

Tavus live entitlement, billing and conversation acceptance remain unverified.
No hosted video call, paid upgrade, media upload or training was performed.
Cloned voice, dedicated microphone input, custom imports, broader provider
profiles and hosted operational access are deferred. The normal configured
language-model usage still applies to local Avatar Chat.
