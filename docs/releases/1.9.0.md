# NetClaw 1.9.0

Spec: [150-vscode-extension](../../specs/150-vscode-extension/spec.md)

Prepared source version, **not a published release**. The owner authorized merging
implementation to main and explicitly continues to prohibit publication. Do not
create a release tag, GitHub release or Marketplace upload under this instruction.

## Changes

Add the NetClaw VS Code workspace extension for an existing compatible NetClaw or
Risk. It provides identity-bound host-local connections, 22 observation views,
Chat with reviewed context, Canvas, local Avatar, integrated RAG retrieval and
citations, reviewed existing settings, service-command staging and an optional
official-SDK adapter for Copilot, Claude Code and Codex. The mobile logo is retained.
The adapter cannot approve or directly apply its own proposals. NetClaw retains
execution, NCFED, authorization and audit responsibility. No base runtime,
installer, credentials or MCP registration changes are included.

## Upgrade and compatibility

The extension component remains `NetClaw.netclaw@0.1.0`; repository source metadata
advances independently to 1.9.0. No running installation migration is performed.
Use a compatible existing HUD and VS Code >=1.102; Windows-hosted NetClaw runs in
the selected WSL workspace. Retain normal workspace trust and review dialogs.
Existing optional/runtime-specific capability limits remain visible; see the
[extension guide](https://github.com/automateyournetwork/netclaw/blob/e34db232b775ef0308f5e47d309c3e32609be77f/extensions/netclaw-vscode/README.md).

The committed unpublished VSIX is `netclaw-0.1.0-mac-final.vsix`, SHA-256
`b13bdfe68c4086bd22edb7521d87443837127f1c70addae08e302b352725c6b8`.
Do not rebuild it merely to resume validation. Disable or uninstall the extension
to stop editor access; its independent backend and private retained state remain.

## Validation and known limitations

All 20 test cases passed across default and opt-in RAG runs. Exact installed Mac
checks cover VS Code 1.102/1.141, actual RAG, selected context and a real configured
OpenClaw provider; current-editor installed lifecycle passed. The older editor's
post-uninstall CLI inventory abort and successful follow-up are recorded in
[Mac evidence](https://github.com/automateyournetwork/netclaw/blob/e34db232b775ef0308f5e47d309c3e32609be77f/specs/150-vscode-extension/evidence/mac-final.md).

Real Windows/WSL qualification includes Copilot, Claude Code and Codex, Chat/RAG,
Canvas/Avatar and lifecycle for the preceding package. Its Copilot permission
deviation and subsequent Default-permissions recheck remain explicit in
[WSL evidence](https://github.com/automateyournetwork/netclaw/blob/e34db232b775ef0308f5e47d309c3e32609be77f/specs/150-vscode-extension/evidence/wsl-followup.md).
The exact final artifact also passed the targeted actual Windows/WSL RAG check:
live cited retrieval, busy controls across tab changes, native cancellation,
isolated delayed/error reads and disconnect with late completion. See the
[final WSL evidence](../../specs/150-vscode-extension/evidence/wsl-final.md).
No product bytes changed; no further Mac handoff is required for this validation.
Live Hermes, Remote SSH/second-distribution/reboot and device-write acceptance are
not claimed. Advanced enhancements and aesthetics belong to a future Spec151.
Implementation completion does not mark publication task T023 complete.
