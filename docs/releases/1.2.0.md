# NetClaw 1.2.0

Spec: [132 — Equinix Fabric + Network Edge](https://github.com/automateyournetwork/netclaw/blob/v1.2.0/specs/132-equinix-fabric-mcp/spec.md)

Adds the official Equinix MCP through a pinned OAuth bridge and local policy boundary,
two skills, an Equinix Risk specialist, installer/setup support and HUD entries.
Documented create/update/actions require a real baseline, exact-operation approved
Implement CR, incident precheck and GAIT. Reads work independently of write opt-in.
No delete tools are exposed upstream; Network Edge's announced surface is visibility.

## Upgrade and compatibility

Optional component; existing installations stay disabled until EQUINIX_ENABLED=true.
Run setup and complete browser consent per [operator guide](https://github.com/automateyournetwork/netclaw/blob/v1.2.0/docs/EQUINIX.md). Writes
need separate opt-in and dedicated ServiceNow verifier credentials. No existing
runtime configuration, federation enrollment or cloud resource is changed by this
source release. No native setup.exe was built; shared Bash/WSL setup is updated.

## Validation and limitations

26 focused offline tests passed; catalog, inventory, portability, package/dependency,
startup and SDD checks passed; HUD production build passed (existing chunk-size warning).
See [evidence](https://github.com/automateyournetwork/netclaw/blob/v1.2.0/specs/132-equinix-fabric-mcp/evidence) and
[handoff](https://github.com/automateyournetwork/netclaw/blob/v1.2.0/specs/132-equinix-fabric-mcp/handoff.md).
Live OAuth, preview manifest compatibility, real gated execution/read-back and WSL
acceptance remain account/platform-owner checks. No paid provisioning or live writes
were performed. Source release only; no compiled Windows or mobile binaries are included.
