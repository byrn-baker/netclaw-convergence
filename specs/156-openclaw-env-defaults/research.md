# Research: issue #262

- Decision: use per-server variable defaults outside runtime template syntax. Rationale: 159 expressions/120 variables/64 servers today, including three URL fields; actual pinned OpenClaw returns fallback syntax literally, rejects absent/empty bare references, and accepts literal empty strings. Alternatives: bare replacement alone breaks optional settings; shell evaluation is unsafe; global defaults conflate integration scopes.
- Decision: absent or empty optional input uses its documented fallback; nonempty input is preserved as a native reference. Rationale: prevents secret materialization and preserves current literal semantics. Adding a previously missing override requires regenerating registrations; documented explicitly.
- Decision: all ITSM_LAB_MODE defaults false. Rationale: current Nautobot templates contain true while Aruba and .env.example use false; explicit lab opt-in takes precedence. No live configuration is changed.
- Decision: retain recognized old fallback compatibility only at generator/migration boundaries. Merge replaces exact known legacy references, preserves custom values and refuses unsupported custom fallback expressions. URLs and aliased Check Point keys are included.
- Evidence: actual pure resolver at pinned OpenClaw package `dist/env-substitution-CATXLg7n.js` exported `r`; no process/provider started. Native errors on missing and empty variables are observed, not inferred. Local source: scripts/lib/setup_registration.py, scripts/install-mcp-config.py, scripts/openclaw-to-hermes-mcp.py, scripts/migrate-tls-registration.py.
- Read-only research delegated through Spec Kit plan Phase 0. No unresolved clarification remains.
- Version boundary: current [OpenClaw documentation](https://docs.openclaw.ai/gateway/config-secrets-env#default-values) now documents fallbacks, and upstream issue 149551 closed September 23. This fix targets compatibility with NetClaw's qualified 2026.7.1-2 pin and older installations; it does not assert the limitation persists in every newer release. No runtime upgrade is included.
