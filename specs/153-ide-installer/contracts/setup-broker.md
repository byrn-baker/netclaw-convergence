# Setup broker

Transport: one Unix-domain socket per active editor window on macOS/WSL, in an unpredictable short 0700 owned directory. Socket and registration file 0600. Byte length <=100 for macOS compatibility. The registration contains schema/session/host/registration IDs, socket path, expiry and a random 256-bit token. No token in argv, environment, tool output, telemetry or webview state. Use the file path in MCP launch arguments; reject symlink/foreign/permissive files.

Length-bounded JSON Lines request envelope: `{protocol:1, registrationId, sessionId, requestId, token, operation, params}`. Authenticate using constant-time token comparison; validate session/expiry/enabled state and every operation schema before dispatch. One response per request; bounded pending requests, timeouts and connection count. Never log envelopes. On shutdown revoke registrations, destroy clients, discard memory secrets and request pause for owned engine sessions. Rotation invalidates old windows/adapters.

Permitted operations map one-to-one to setup-tools.md. Secret-entry opens the native UI and directly writes the response to the engine, returning presence only. Review submission opens a native effect preview; its human action invokes the extension's engine channel, not a broker apply endpoint. Status subscriptions contain only redacted projections. No endpoint receives an approval token or accepts a secret value. Unsupported operations always refuse, including operation names supplied through nested properties.

Allow stable management and setup definitions to coexist without binding setup to the selected existing claw. Provisioning registration IDs use session IDs, management registrations use installation identities. Terminal registration previews use `process.execPath`, the bundled adapter and `ELECTRON_RUN_AS_NODE=1`; no PATH Node dependency or automatic registration execution. Source stamp/path/expiry are revalidated after editor upgrades. Consent shows client scope/destination and collisions; never overwrite an unrelated registration.
