# Data model

- **ViewModel**: kind, title, description, provenance (source/observedAt/installation), metrics and sections of named cards/facts. Missing, false and zero remain distinct. Raw details are bounded and collapsed. State: loading → ready/empty/error → invalidated. Filter and page remain local.
- **TestbedSnapshot**: schemaVersion=1, installationId, targetId (server path hash), source, revision (SHA256 exact bytes), masked content, safe device summaries, backup IDs, capability/limits. Device key is original YAML key. No graph slug ID is accepted as authority.
- **TestbedOperation**: create/update/remove, document/import or restore. Carries fixed fields, selected connection, format/mode/conflict policy and in-memory text as applicable. Unknown fields/operations rejected. Full documents are parsed inertly; CSV columns explicitly defined in contract.
- **TestbedPreview**: baseline revision, deterministic digest, added/changed/removed IDs, shared-change flag, affected IDs, secret path intents, target source and backup/revocation explanation. No secret values. Commit repeats preparation and compares digest.
- **SecretKeepToken**: deterministic path+revision-bound opaque token referring only to unchanged baseline scalar. Tokens cannot move, be forged or survive stale baselines. %ENV references stay textual. New literal input remains in memory only.
- **McpDescriptor**: integrationId, name, notes, fields, component IDs, operations and fallback reason. Field: key, label, kind, requirement, help, sharedWith, isSet. Unknown classification defaults confidential and requirement unknown.
- **ConfigurationChange**: integrationId, revision, changes with keep/replace/clear. Only changed allowlisted keys submitted. Save verifies values server-side, returns presence+revision; never reports runtimeLoaded/endpointVerified as true without separate evidence.
- **SetupReview**: operationId, fixed action/component, selected host/runtime/installation, verified root/home, fixed argv, affected files/helper hashes and baseline revision, interruption/recovery note. Prepared → cancelled or running → verified/failed/unknown. No automatic replay after host interruption. Evidence contains controlled statuses and hashes, never stdout/secret values.
- **TopologyGraph**: sourceKind=bgp-sessions, nodes from local speaker/peer records and edges only for reported sessions. State is source-reported, not physical reachability. View selection is shared with accessible controls; geometry max200 while full source list remains available.
- **SecurityTarget**: product, existing runtime home/kind/installation identity, native-selected executable and security home (DefenseClaw) or config root/gateway/workspace/sandbox (OpenShell). Shared host perimeter, not presumed installation-private.
- **SecuritySnapshot**: explicit target, observed version/capabilities, redacted status/log rows, editable allowlisted policy projection, exact baseline hashes, and configured/loaded/enforced distinctions. Unknown schemas are read-only.
- **SecurityReview**: in-memory prepared mutation, reason, before/after scope summary, weakening flag, private original and target/config fingerprints; prepared → cancelled/running → verified/failed/unknown. No replay or automatic rollback over external changes.
