# Testbed document API contract

All new routes use existing local-access controls and require the selected installation header. Server selects the file; no caller path is accepted. Source limit256KiB UTF-8, depth32, bounded alias expansion. Masked YAML is bounded at512KiB; the testbed bridge alone allows1MiB messages, while other views retain their existing limits. Oversized projections fail explicitly without truncation. Duplicate keys, unsafe property keys, nonmapping devices, custom tags and ambiguous transforms fail with controlled messages without source snippets. Parsing never resolves ENV/extends/classes or connects devices.

- GET `/api/testbed/document`: TestbedSnapshot; exact source path and distinction from running pyATS configuration; safe cards and masked YAML. Missing file may yield explicit empty editable inventory; malformed existing source is an error.
- POST `/api/testbed/preview`: `{targetId,revision,operation}` → preview, including digest and all affected IDs. Read-only.
- PUT `/api/testbed/document`: same plus `{digest,confirm:true}`. Recompute, compare, reject stale review409. Block affected active terminals; revoke affected grants and forget logins before private backup/atomic write. Verify bytes after write, return revision/recovery ID. Never retry. Shared defaults/credential changes affect all devices. A failed write after revocation reports that side effect.
- POST `/api/testbed/export`: `{targetId,revision,format,credentials:'redacted'|'include'}` → host-only content+extension+limitations. Native save path and explicit include-credentials review required. Private export mode0600; never persist to webview. YAML include is exact; JSON semantic; redacted formats labeled; CSV always excludes credentials.
- Restore operation references opaque existing backup ID and uses the same preview/commit path. No arbitrary path. Private backups remain mode0600 under mode0700 directory.

Guided fields: id(create only), alias/type/os/platform, selected connection name/protocol/host/port. Preserve everything else through CST. Reject shared alias edits that could mutate unintended devices; advanced YAML remains available. Remove previews corresponding topology entry removal. Cards never expose arbitrary objects.

Full YAML/JSON import: replace whole document explicitly, or merge device entries with explicit error/skip/replace duplicate policy; reject imported non-device top-level changes in merge instead of dropping them. Preview removed devices before replacement.

CSV columns: `id,alias,type,os,platform,connection,protocol,host,port`. Require id; require named connection for supplied connection columns. Patch only supplied columns, preserve unrepresented advanced fields, never remove unseen devices. Empty optional metadata clears; empty required connection values and invalid port error. A blank CSV port leaves an existing value untouched and leaves an absent value unspecified. New entries require os and valid connection host/protocol. UTF-8 BOM, CRLF, quotes, escaped quotes and multiline fields supported. Reject duplicate (id,connection) pairs, conflicting device metadata across rows for one id, duplicate headers, unknown columns, malformed rows with row/column locations. Export one row per selected available connection; explicitly identify omissions/limits; formula-leading text neutralized and disclosed. YAML/JSON recommended for full fidelity.

Mask credentials/password containers and secret scalar keys; keep %ENV references. Restore keep tokens only at original scalar paths in unchanged baseline. Never persist drafts. Mode changes preserve separate drafts or require save/discard/cancel. Review shows paths/intents, never literals. Unknown advanced data is preserved and omitted from ordinary cards.

Older HUD: editing unavailable with clear guidance; never use legacy raw writer fallback. This API edits configured inventory only; it neither grants collector access nor proves which file a running pyATS MCP uses.
