# Comms setup contracts

## Discovery

Wizard, CLI and assistant read the same validated catalog. Discovery is local and credential-free. It returns provider/name/aliases, kind, native/runtime mapping, eligible roles, prerequisite descriptions, guide links, implementation disposition and recorded qualification. It must not instantiate a provider adapter, install dependencies, authenticate, launch a listener or import an MCP module that starts services.

Search for Twilio resolves its SMS paths, optional runtime telephony and existing NetClaw MCP/skills. Search for Zoom resolves the existing meeting integration, with RTMS/input/panel/history distinctions and Border placement requirements. Existing member roles see eligible tools without receiving Border conversation-channel credentials.

## Drafting

Adding/removing a channel preserves every retained channel's settings. Removing a channel clears only references owned solely by that selection; no external account or message deletion occurs. Native secure prompts collect secret values at apply time. Non-secret typed access settings are reviewed with the plan. Native identifiers never bypass canonical plan-ID validation.

A selected incompatible/unimplemented option stays visible with a reason and cannot produce an executable success claim. Choosing None is explicit and remains supported. Member tool selection uses existing capability/settings contracts; it does not populate `claw.channels`.

## Review and apply

The engine review includes source, catalog and Comms manifest hashes, selected homes, exact dependency sources/versions, fixed actions, service placement and disclosed network/external effects. Changing any of them invalidates review. An assistant may draft an action but cannot grant native review authority.

Each native handoff is bound to one owner and exact effect. The Python transport and TypeScript terminal gate must agree on allowed IDs. The private terminal inherits the existing lock/cancellation protocol. Its arbitrary output is not a report or assistant transcript. Secret values are never placed in OS process arguments or persisted UI state.

A native setup helper may invoke only a version-checked, selected-platform setup contract. A broad wizard that can change other accounts or install/start unrelated services is not an acceptable substitute. A per-platform helper may use upstream setup code only after its actual dependency/side-effect behavior is covered by the reviewed contract.

The adapter records artifact intent before writes and verifies the selected configuration afterward. Provider/MCP settings written in earlier phases must remain intact. Service activation is blocked by any unsettled required Comms configuration effect.

## Owned messaging services

OpenClaw retains its existing managed gateway. Hermes uses the pinned foreground gateway command through the same ownership framework when messaging is selected; it never invokes the runtime's global service installer or migrates profiles. Observe selected-home process identity, version, start generation and fresh per-platform status; a configured-platform list is not a live connection check.

Automatic startup messages, pending-event consumption and listener exposure must be suppressed for isolated qualification or included in the exact reviewed activation scope. An adapter with unbounded startup behavior cannot be activated as an effect-free installer check.

## Twilio

Treat native SMS, runtime voice and NetClaw MCP credentials as separate contracts. Guide sender capability, approved recipients, signature-validated callback and applicable provider prerequisites. Never purchase a number or change an unrelated number's routes implicitly.

An auth-token SMS path must not consume an API-key secret as a substitute. The core MCP's credentials must not appear in OS argv; use a pinned audited environment-auth adapter if the upstream CLI lacks that facility. Managed inbound voice must preserve selected-runtime routing and fail closed rather than invoke a fallback model/tool path outside that binding.

Submission, delivery and voice outcomes are independently reported. Local setup qualification does not make a call or send an SMS/MMS. Live tests show their exact sender, recipient, content/media and effect before approval.

## Zoom

A full Zoom MCP component is member/Focused-owned under current role rules. Where meeting input targets a Border, generate a dedicated same-host local binding and verify its two ends without adopting another installation. Do not expose the loopback-only bridge remotely.

An inert mode is allowed only for transient MCP discovery; it must prevent background listener/capture startup and refuse effectful tool invocation. Actual activation uses one installation-owned process for both tools and background state. Reports distinguish SDK/configuration, webhook authentication, bridge binding, panel, history connector and optional camera readiness. Auth/account requirements are based on the chosen Zoom path, not a blanket requirement for every possible mode.

## Verification and reports

The wizard materializes selected tests, including owner/channel/direction/destination reference. It cannot represent tier selection alone as completed testing. Native review is consumed before an external effect and journaled with an unknown initial outcome. Cancellation sends nothing; uncertain execution pauses before another external test.

Authentication and transport probes must be described as network activity where applicable. Inbound challenges cannot silently invoke a model or device/domain tool. Missing safe verification support stays explicitly unverified. Report projection is structural, with separate per-channel dimensions and no unreviewed private identifiers.

## Resume and cleanup

Resume observes existing artifacts/process identity and private receipts before deciding whether an action is safely repeatable. Changed native configuration invalidates stale evidence. Cleanup removes only tracked setup-owned resources and processes, preserving accounts, external messages, shared bindings and retained channel credentials. No bulk `.env` import, global-home migration or owner-runtime adoption is part of this contract.
