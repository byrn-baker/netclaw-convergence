# A separate home for each claw

Choose Focused or Risk, select a harness and provider for each claw, then review the exact installation plan. Existing NetClaw installations remain available in Connections.

Windows users start with read-only WSL checks and a separate reviewed handoff.
# Communication setup

Use **Comms** to select multiple channels for the chosen OpenClaw or Hermes
runtime, or explicitly None. Search also finds Twilio API/voice tools and Zoom
with their Focused/member ownership. Follow **Account preparation & setup guide**
before entering credentials through native secure prompts. Each channel reports
configuration, authentication, connection and inbound/outbound evidence separately.
