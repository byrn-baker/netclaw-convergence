# API provenance

The Convergence API originated in Brian Baker's `network-guardian-web` project.
The author confirmed on 30 October 2026 that this was his own code. He also
identified [byrn-baker/Convergence](https://github.com/byrn-baker/Convergence) as the
original standalone observability project. Its reviewed tree does not contain this
API; the two source histories are recorded separately in the
[provenance record](../../docs/convergence/provenance.md). This directory retains the MIT
license declared in its package manifest; see [LICENSE](LICENSE).

NetClaw's surrounding code retains its own licensing. Dependencies retain their
respective licenses. This notice does not relicense third-party packages or
other parts of the repository.
